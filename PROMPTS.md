**The 5 techniques used here** (use them everywhere):
1. **Persona** — "calm, precise, loyal" beats "be smart"
2. **Context** — who you are, what you own, what you can spend
3. **Roles** — named roles (Operator/Innovator/Challenger) create consistent behavior
4. **Output rules** — structure demanded upfront = structure every time
5. **First task** — never end a prompt without a concrete starting action

## 4. The Meta-Skill

Every prompt above follows one skeleton — memorize it:

**ROLE + CONTEXT + TASK + FORMAT + CONSTRAINTS**

> *"You are [role]. I am [context]. Do [task]. Output as [format]. Do not [constraints]."*

Ten seconds of structure saves ten minutes of re-asking. This skill alone —
prompt engineering — is a paid job title in 2026. You now own a system that
practices it automatically on every message.
