🖥️ MACBOOK (Late 2012)

  • Turn on FileVault disk encryption — System Preferences → Security & Privacy.
  • macOS Catalina gets no security updates — the browser is your main attack surface, keep Firefox ESR updated.
  • Set a firmware password (Recovery → Utilities) to block USB boot attacks.
  • Ask JARVIS in chat: /security harden my old macbook

📱 PHONE

  • Screen lock with 6+ digits or biometrics; auto-lock at 30s.
  • Never install APKs from random websites / WhatsApp links — top malware vector in India.
  • Audit app permissions monthly; never share OTPs — no real bank asks.

🔐 ACCOUNTS & NETWORK

  • 2FA everywhere (authenticator app > SMS): Gmail, bank, UPI-linked, Instagram first.
  • Password manager (Bitwarden — free) so every password is unique. Check breaches: haveibeenpwned.com
  • Change your router's default admin password; WPA2/WPA3 only; careful on public WiFi.
